## 2. 使用说明

本模板用于同时服务以下三类工作：

- 后端验证同步、派生字段和风险计算
- 前端联调首页、明细页和配置页展示
- QA 验证规则正确性、提醒触发和数据异常分流

建议使用方法：

1. 先确认统一测试基准时间和仓库时区
2. 再确认源数据样例
3. 最后确认预期风险结果、首页汇总结果和提醒结果

## 3. 测试基准

本模板先给出一套可直接使用的参考基准，后续可按实际仓库替换。

- 仓库编号：`WH-US-001`
- 仓库名称：美国 1 号仓
- 仓库本地时区：`-05:00`
- 风险计算基准时间：`2026-05-04T10:00:00-05:00`
- 出库预警提前量：4 小时
- 到仓不齐预警提前量：12 小时
- 上架预警提前量：12 小时

说明：

- 所有“剩余时长”和“超时时长”均相对上述基准时间计算
- 若后续更换基准时间，需要同步调整预期结果
